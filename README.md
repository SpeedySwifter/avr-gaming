# AVR Gaming

> **WE DON'T JUST PLAY THE GAME – WE DEFINE IT.**

Moderne Website für die AVR Gaming eSport-Organisation – entwickelt mit Next.js, TypeScript und Tailwind CSS.

🌐 **Live:** [avr-gaming.vercel.app](https://avr-gaming.vercel.app)

---

## 📋 Über das Projekt

AVR Gaming ist eine professionelle eSport-Organisation. Diese Website dient als zentrale Plattform für:

- **Team-Präsentation** – Showcase aller aktiven Teams und Spieler
- **News & Updates** – Aktuelle Nachrichten aus der eSport-Szene
- **Awards & Erfolge** – Übersicht über Turniere und Siege
- **Sponsoren-Integration** – Präsentation der Partner und Unterstützer
- **Support & Donations** – Möglichkeiten zur Unterstützung der Organisation

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) – React-basiertes Framework mit SSR/SSG
- **Sprache:** [TypeScript](https://www.typescriptlang.org/) – Type-sichere Entwicklung
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) – Utility-First CSS Framework
- **Deployment:** [Vercel](https://vercel.com/) – Automatisches Deployment
- **SEO:** Next-SEO – Optimierte Suchmaschinenoptimierung

---

## 🛠️ Installation & Entwicklung

### Voraussetzungen

- Node.js 16.x oder höher
- npm oder yarn

### Setup

```bash
# Repository klonen
git clone https://github.com/SpeedySwifter/avr-gaming.git

# In Projektverzeichnis wechseln
cd avr-gaming

# Dependencies installieren
npm install

# Development Server starten
npm run dev
```

Die Entwicklungsumgebung läuft auf [http://localhost:3000](http://localhost:3000)
